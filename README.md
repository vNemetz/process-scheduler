<h1>Operating System Process Scheduler</h1>
<h2>
  Authors: João Pedro Veloso, Vinícius Nemetz Grabovski
</h2>
<p>
  This is the repository for an Operating System Process Scheduler, written in C++ and GUI uses SFML library.
</p>

<h2>How to compile run the project</h2>
<p>Clone the repository</p>
<p> Run the following commands in the terminal</p>

```
mkdir build && cd build <br>
cmake ..<br>
cmake --build .
```
